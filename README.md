# SMK37 Pro Custom

Firmware experimental baseado no projeto SMK37 OPEN da M-VAVE, com modificações para controlar o Yamaha MODX+ via MIDI.

## Objetivo

Personalizar o mapeamento MIDI das teclas, pads e encoders do SMK37 Pro.

## Estado do projeto

**Experimental — ainda não testado no hardware.**

Não instalar o firmware até que o procedimento de atualização e recuperação seja validado.
